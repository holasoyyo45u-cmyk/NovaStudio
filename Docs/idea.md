# Nova Studio

Nova Studio es un asistente inteligente para crear y administrar proyectos.

## Objetivo

Crear una herramienta que permita usar inteligencia artificial para transformar instrucciones normales en acciones dentro de un entorno de desarrollo.

## Sistema

Nova funciona por módulos:

- NovaCore: cerebro y lógica de comandos.
- API: comunicación con servicios externos.
- Luau: scripts y ejemplos para Roblox.
- Docs: documentación del proyecto.

## Futuro

Nova podrá:
- Interpretar instrucciones en lenguaje natural.
- Generar código.
- Ayudar a crear objetos y sistemas.
- Organizar proyectos.
